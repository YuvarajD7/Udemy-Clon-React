# Udemy Clone – React

A responsive Udemy-inspired web application built using **React.js** to recreate the look and feel of an online learning platform. This project demonstrates component-based development and reusable UI elements.

## 🚀 Features

- **Responsive UI** – Clean layout inspired by the Udemy learning platform.
- **Course Cards** – Display course images and details in an organized layout.
- **Reusable Components** – Built using React components for better code organization.
- **Navigation Bar** – Easy navigation across the application.
- **Course Recommendations** – Show recommended courses to users.
- **Modern Design** – Simple and user-friendly interface.

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YuvarajD7/Udemy-Clon-React.git
```

### 2. Navigate to the project folder

```bash
cd Udemy-Clon-React
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm start
```

Open the local URL displayed in your terminal, usually `http://localhost:3000`.
